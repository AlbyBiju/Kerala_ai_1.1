# Coding Standards & Architecture Rules

## 1. Backend Standards (Python 3.11+, FastAPI)

### Async Architecture
- All database I/O must use SQLAlchemy async sessions with the `asyncpg` driver:
  ```python
  async with async_session_factory() as session:
      ...
  ```
- Fast endpoints must use dependency injection (`Depends(get_db)`, `Depends(get_current_session)`).
- Never block the event loop with synchronous file I/O or heavy CPU work; run CPU-bound parsing/OCR in threadpools or background tasks (`BackgroundTasks`).

### Typing & Validation
- Enforce strict typing with type hints on all public functions, arguments, and return types. Verify with `mypy`.
- Request and response validation must use Pydantic v2 schemas (`BaseModel`, `Field`, `ConfigDict(from_attributes=True)`).
- Environment settings must inherit from `pydantic_settings.BaseSettings` with default values and `.env` source.

### Error Handling & Responses
- Return standard HTTP error status codes with descriptive `{ "detail": "..." }` payloads.
- Use explicit HTTP codes: `201 Created` for session creation, `202 Accepted` for asynchronous ingestion/analysis jobs, `404 Not Found` for missing resources, `413 Payload Too Large` for files exceeding 20 MB.

### Database Migrations
- Never alter database models without creating an autogenerated Alembic migration:
  ```bash
  alembic revision --autogenerate -m "<descriptive_message>"
  alembic upgrade head
  ```

## 2. Frontend Standards (React, TypeScript, TailwindCSS)

### Type Safety
- All components, props, state, and API models must be explicitly typed in TypeScript (`.tsx` / `.ts`).
- Avoid `any`. Define domain interfaces in `src/types/` corresponding to the response schemas in [REFERENCE.md](file:///c:/Users/Abel%20Jose/Desktop/keralai/Kerala_ai/REFERENCE.md).

### State & Data Fetching
- Use TanStack React Query (`useQuery`, `useMutation`) for all server state.
- Do NOT use `useEffect` for data fetching.
- Use polling with `refetchInterval` (e.g., 3000ms) when waiting for background extraction or analysis tasks to complete.
- Implement optimistic updates for user actions like changing discrepancy status (`open` -> `acknowledged` -> `resolved`).

### Styling & UX
- Use TailwindCSS utility classes maintaining consistent spacing, typography, and color tokens.
- Design for responsive layouts (desktop, tablet, mobile).
- Always include accessible loading spinners, skeleton states, and empty states.
- Surface error messages and success feedback using `react-hot-toast`.
